# Harness

Template personnel de *harness engineering* pour **Claude Code**, autour d'[OpenSpec](https://github.com/Fission-AI/OpenSpec) : **skills**, **agents**, **rules**, **hooks** et **contrôles CI** à appliquer dans chaque projet, **quelle que soit la stack**.

Usage visé (disponible à la fin de la phase 0) :

```bash
uvx copier copy --trust gh:PatayEnCroute/Harness .   # 1. installer dans un projet
# 2. dans Claude Code : /hx-setup                      → personnalisation à la stack
uvx copier update --trust                             # plus tard : mettre à jour
```
