# Harness

Template personnel de *harness engineering* autour d'[OpenSpec](https://github.com/Fission-AI/OpenSpec) : **skills**, **agents**, **rules**, **hooks** et **contrôles CI** à appliquer dans chaque projet, agnostique de l'outil IA, de la stack et de la CI.

Usage visé (disponible à la fin de la phase 0) :

```bash
uvx copier copy --trust gh:PatayEnCroute/Harness mon-projet   # installer
uvx copier update --trust                                      # mettre à jour un projet
```
