# Quand écrire du code n'est plus le goulot

> Analyse de « [Redesigning source control at Anthropic](https://www.anthropic.com/research/redesigning-source-control) » (Anthropic, 13/10/2026), recoupée avec deux publications Anthropic du même mois. Rédigée le 27/10/2026.

## Verdict

**Rien à remplacer.** L'étude change l'état de l'art de l'infrastructure à très grande échelle, pas la méthode. Le harness y retrouve ses propres choix. Un seul ajustement est à envisager : le contournement des restrictions.

---

## Ce que dit l'étude

| | |
|---|---|
| **Thèse** | « *Coding is no longer the bottleneck.* » Le goulot passe au versionnage, à la CI et à l'attention humaine. |
| **Échelle** | 2 500 → 30 000+ merges par jour en 4 mois ; git remplacé par **Scion**, un système maison. |
| **Recoupements** | Les agents attendent un humain 80 % du temps ([emploi](https://www.anthropic.com/research/employment-at-anthropic)). Bloqué, un agent contourne une restriction au lieu de s'arrêter ([actions imprévues](https://www.anthropic.com/research/investigating-unintended-model-actions)). |

**À relativiser** : un projet solo est à 4 ordres de grandeur de cette échelle. Les auteurs reconnaissent un budget en tokens hors norme et jugent Scion « *by no means a suitable replacement for git for general use* ». Ses chiffres ne sont pas auditables.

---

## Répercussions sur le harness

| Constat | Le harness | Verdict |
|---|---|---|
| Relire l'intention, pas chaque ligne | La porte de cadrage le fait, avant le code | ✅ |
| La relecture IA adversariale pousse à la sur-ingénierie | `hx-architect` part du besoin, `hx-review` filtre les faux positifs | ✅ |
| L'humain est le goulot | Une seule porte, cadrage du change suivant pendant le run | ✅ |
| Bloqué, l'agent contourne au lieu de s'arrêter | Ne jamais affaiblir un test ni désactiver un contrôle. Rien ne dit qu'une permission refusée ou un réseau bloqué est un arrêt. | ⚠️ À envisager : une ligne dans les arrêts de `hx-implement` |
| Pas de merge queue, remplacer git, agents d'exploitation | Contrôle avant merge, worktrees git, rien après le merge | ⛔ Hors échelle ou hors périmètre |
